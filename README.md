# 🎤 Pense-Bête Vocal

Une application web premium pour capturer vos idées par la voix. Vos paroles sont instantanément transformées en post-its colorés sur un tableau en liège interactif.

![Aperçu](assets/background.png)

## ✨ Fonctionnalités
- **Retranscription IA** : Conversion automatique de la parole en texte (via Web Speech API).
- **Design Premium** : Interface "Glassmorphism", post-its réalistes avec animations fluides.
- **Sauvegarde Locale** : Les notes persistent entre les sessions grâce au `localStorage`.
- **Export/Import** : Sauvegardez vos notes dans un fichier JSON pour les transférer ou les restaurer.
- **Responsive** : Optimisé pour une utilisation sur mobile et tablette.

## 🚀 Utilisation
1. Ouvrez l'application.
2. Cliquez sur le micro central (ou appuyez sur **Espace**).
3. Parlez ! Votre note apparaît instantanément.
4. Utilisez les boutons latéraux pour sauvegarder ou restaurer vos données.

## 🛠️ Installation locale
```bash
# Clonez le dépôt
git clone https://github.com/kentin2900/pense-bete-vocal.git

# Ouvrez index.html dans votre navigateur
# Note : Pour le micro, utilisez un serveur local (ex: Live Server) ou GitHub Pages
```
